# Security policy

`docker ephemeral` deletes Docker resources, so a bug that removes something it
did not create is treated as a security issue.

## Reporting

Please **do not open a public issue**. Report it privately through
[GitHub Security Advisories](https://github.com/wendersoon/docker-ephemeral/security/advisories/new).

Include the version (`docker ephemeral version`), the Docker version and the
steps to reproduce. You can expect an answer within a few days.

## Supported versions

Only the latest release receives fixes.
